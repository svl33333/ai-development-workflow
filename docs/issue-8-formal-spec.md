# Issue #8 正式仕様

## 実行単位

承認済みの人間向け計画と、同一の `approval_digest` に束縛された execution manifest を実行の正本とする。manifest はDAGとして検証し、依存関係の循環・未知参照・重複ID・並行範囲の重複を拒否する。並行数の初期値は3である。

## 子タスク境界

子タスクは専用worktreeで実装・テスト・ローカルコミットだけを行う。親state、統合ブランチ、GitHub公開、マージにはアクセスできない。結果にはテスト証跡、commit、artifact digest、ローカルレビュー記録を含め、承認済みローカルレビューなしには統合できない。

## 世代と承認

オーケストレーターのgenerationはfencing tokenであり、後継世代が有効化された後の旧世代による状態変更・子起動・キャンセル・統合・結果取り込みを拒否する。成果物の提示、レビュー、承認はrevisionとdigestへ束縛し、対象が変わった時点で無効化する。

## 完了条件

子タスクの統合、段階テスト、最終テスト、ChatGPTによる最終PRレビューと修正ループを完了し、最終PR成果物を提示して人間承認を得る。加えて、実際のCodex＋ChatGPT/C2C接続による手動ライブ検証を最低1回行い、結果を記録する。
