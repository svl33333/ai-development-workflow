# Independent plan review

計画作成側とは別に、実装計画レビュー専用のChatGPT会話を1つ用意する。計画作成側の会話履歴・自己評価は渡さず、Issue・仕様・計画・現行リポジトリだけを根拠に第1ラウンドをレビューする。第2ラウンド以降は同じレビュー会話を再開し、その会話自身の過去の指摘・採否記録と修正版計画を照合して、前回指摘の修正状況を確認する。

早期ラウンドで重大な問題が見つからない場合も、計画作成側が採否・変更不要の根拠を記録してから、同じレビュー会話で最低3ラウンド実施する。計画作成会話とレビュー会話の識別情報、各ラウンドの指摘・採否・根拠を状態正本へ保存する。重大な設計判断、未解決のCritical／High、または人間の依頼がある場合だけ、新規会話によるセカンドオピニオンを追加できる。工程専用レビュー会話が利用不能なら停止し、人間承認後にだけ代替会話へ引き継ぐ。
