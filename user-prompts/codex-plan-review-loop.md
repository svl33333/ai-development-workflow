# Codex plan review loop 開始プロンプト

レビュー用に新しいCodexタスクを作成し、以下を貼り付けて使用する。

```text
$codex-plan-review-loop
mode: launcher
計画側タスクID: <現在の計画策定タスクID>
レビューワーモデル: gpt-5.6-luna

実装計画: <リポジトリ内の実装計画ファイルのパス>
最大ラウンド: 3
重点観点: 受入条件、既存構成との整合性、テスト、移行とロールバック

この計画を、会話履歴を共有しない新規Codexタスクで独立レビューしてください。
計画側の会話内容や自己評価はレビュータスクへ渡さないでください。
各ラウンドでは、レビュー結果の保存、指摘ごとの採否記録、計画更新、差分検証を
完了してから、次ラウンドを新しいレビューワータスクで実行してください。
レビューワーには計画本文と基準リビジョンを渡し、計画側タスクIDは結果返却専用の
callback metadataとしてだけ渡してください。レビューワーは結果を最終回答するだけでなく、
同じ結果をcallback先へ1回送信してください。
レビュー側では計画の直接編集、実装、仕様確定、コミット、マージを行わないでください。
```

## 使い方

1. 計画策定タスクで実装計画を保存する。
2. Codexで新しいレビュー用タスクを作成する。
3. `<実装計画ファイルのパス>`を置き換えて送信する。
4. launcherが新規レビューワータスクを起動し、レビューワーからcallbackで結果を受け取る。
5. 指摘を保存・採否判断し、計画を更新して差分検証を完了してから、次ラウンドを新しいレビューワータスクで実行する。
6. `APPROVE`、最大ラウンド到達、または人間判断へのエスカレーションを確認する。

仕様確定と実装開始は、レビュー完了後にユーザーが明示的に承認してから行う。
