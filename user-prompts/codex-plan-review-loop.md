# Codex plan review loop 開始プロンプト

レビュー用に新しいCodexタスクを作成し、以下を貼り付けて使用する。

```text
$codex-plan-review-loop

実装計画: <リポジトリ内の実装計画ファイルのパス>
最大ラウンド: 3
重点観点: 受入条件、既存構成との整合性、テスト、移行とロールバック

この計画を、会話履歴を共有しない新規Codexタスクで独立レビューしてください。
計画側の会話内容や自己評価はレビュータスクへ渡さないでください。
各ラウンドのレビュー結果だけを受け取り、内容を確認して計画を更新したうえで、
次ラウンドは新しいレビューワータスクで実行してください。
レビュー側では計画の直接編集、実装、仕様確定、コミット、マージを行わないでください。
```

## 使い方

1. 計画策定タスクで実装計画を保存する。
2. Codexで新しいレビュー用タスクを作成する。
3. `<実装計画ファイルのパス>`を置き換えて送信する。
4. launcherが新規レビューワータスクを起動し、結果を受け取る。
5. 指摘を確認して計画を更新し、次ラウンドは新しいレビューワータスクで実行する。
6. `APPROVE`、最大ラウンド到達、または人間判断へのエスカレーションを確認する。

仕様確定と実装開始は、レビュー完了後にユーザーが明示的に承認してから行う。
